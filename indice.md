# Introducción

Este repositorio fue desarrollado como parte del Trabajo Práctico de Git para la materia Metodología de Sistemas I.

El objetivo del trabajo es aplicar los conceptos vistos durante la cursada relacionados con Git y GitHub, utilizando buenas prácticas de trabajo colaborativo, control de versiones, manejo de ramas, revisiones de código y documentación.

A continuación se encuentran las explicaciones de los distintos comandos utilizados durante la cursada, junto con otros archivos complementarios requeridos por la consigna.
