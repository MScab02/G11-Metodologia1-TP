Durante el desarrollo de este trabajo se utilizaron herramientas basadas en modelos de lenguaje (LLM) como apoyo para algunas tareas.

Las herramientas utilizadas fueron:

ChatGPT: utilizado para resolver dudas sobre Git y GitHub, comprender conceptos vistos en clase y recibir orientación sobre la organización del repositorio.
GitHub Copilot: empleado como asistencia para la redacción y sugerencias de texto.

Todo el contenido incorporado al repositorio fue revisado, comprendido y validado por los integrantes del grupo antes de su inclusión en la versión final del trabajo.
